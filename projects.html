Current Projects

  • Modern Windows 11 Exploit Framework — A project that was brought to me as a challenge from a professor in college. This framework currently includes: a system level reverse shell, keylogger, beacon, status reports of scripts, persistence using a LOLbin from the SC.exe, file discovery/enumeration, and network discovery. This framwork runs undetected by a modern Windows 11 machine. The latest testing had a successful result with Windows Defender and anti-virus protection engaged. The framework runs all files in the RAM of the machine to minimize risk of exposure. I plan to add more to this framework down the road.
  • WiFi Deauthentication Tool — A Kali Linux-based terminal utility that exploits 802.11 protocol vulnerabilities to send deauth packets and disrupt active WiFi connections. Built for educational and testing purposes, it demonstrates low-level network manipulation and command-line control.
